# Commit

Write a commit message for the staged changes.

1. Inspect the staged diff to understand what actually changed and why.
2. Pick the right type: `feat`, `fix`, `refactor`, `docs`, `test`, or `chore`.
3. Write a one-line summary in the imperative mood, under ~72 characters.
4. Add a short body only when the "why" is not obvious from the summary.
5. Never invent changes that are not in the diff.

Output just the commit message — no surrounding prose.
